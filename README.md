# KS ICT Palvelut

### Mikä on "KS ICT Palvelut"?

KS ICT Palvelut on nuoren yrittäjähenkisen kaverin "yritys" yrittäjyyden ihmeellisessä maailmassa.<br>
Haluni yrittäjyyteen juurtaa juurensa jo pitkälle, ja sitä suorastaan akseleroi se, etten millään löytänyt kotikaupungistani itselleni sopivaa työpaikkaa.<br>
Tämän vuoksi, halusinkin alkaa yrittäjäksi, jotta voin tehdä sitä mitä rakastan, sekä saada siitä edes jotakin korviketta.
